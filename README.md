# Korean Study — 한국어 능력 진단

연령과 거주국가를 고려한 한국어 Assessment 웹앱입니다.

## 현재 기능
- 최초 등록: 거주국가, 출생년도, 성, 이름
- 재방문: 성 + 이름으로 브라우저 내 등록정보 확인
- 국가 선택에 따라 입력 용어 현지어 병기 (한국/캐나다/미국/일본/중국)
- 출생년도로 연령대 자동 분류 (나라별 나이 계산 혼선 방지)
- 듣기·말하기·읽기·쓰기 문항
- Chrome/Edge Web Speech API 기반 ko-KR 실시간 음성 인식
- 영역별 1차 보조지표와 인쇄/PDF 결과

## 중요한 평가 원칙
현재 표시 점수는 객관식 정답과 응답 분량을 이용한 보조지표입니다. 브라우저 음성 인식 결과만으로 발음 정확도를 확정하지 않습니다. 최종 Assessment Report는 교사의 발음·유창성·문법·어휘·자연스러움 관찰과 함께 작성합니다.

## 개인정보
현재 프로필/결과는 사용자의 브라우저 localStorage에 저장됩니다. 외부 DB에 개인정보나 음성파일을 전송하지 않는 베타 구조입니다.
